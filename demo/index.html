@elitjs/log browser demo

1) ติดตั้ง extension: chrome://extensions → เปิด Developer mode → Load unpacked → เลือกโฟลเดอร์ extension/
2) เปิด DevTools (F12) → จะมี tab Elit.JS Log โผล่มา
3) กดปุ่มด้านล่างเพื่อปั่น log แล้วดูใน panel — console จะสะอาดเพราะ echo default = warn

config console echo ได้ 3 ทาง (log ยังเข้า panel ครบเสมอไม่ว่าจะตั้งค่าไหน): ปิดหมด · แสดงทุกอย่าง · เหลือ warn/error (default) — หรือใน code: window.ELITJS_LOG_CONFIG = { console: false } ก่อน import, __ELITJS_LOG__.setConsoleLevel(false) ตอน runtime, หรือ dropdown ใน panel

activity ยังไม่เริ่ม — กดปุ่ม level ใด ๆ เพื่อเริ่ม
